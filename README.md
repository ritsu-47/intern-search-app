# 🚀 復活のインターン検索システム

Connpass上の最新インターン・イベント情報を自動収集し、リアルタイムで一覧表示するStreamlitアプリケーションです。

## 🌐 WebアプリURL
[アプリを開く](https://intern-search-app-bmhruxtzxfnvqytv9usbqh.streamlit.app/)

## 📌 機能概要
- **リアルタイム検索**: キーワードに合わせた最新のインターン・イベント情報を取得
- **過去データの自動除外**: 検索当日以降のイベントのみを自動フィルタリングして表示
- **詳細情報の深掘り**: 各イベントの個別ページから「開催日時」「会場」「チケット空き状況」を正確に抽出
- **プログレスバー表示**: データ収集中の進捗状況を視覚的に表示

## 🛠 使用技術
- **Python 3**
- **Streamlit**: WebUIフレームワーク
- **BeautifulSoup4 / Requests**: Webスクレイピング・HTML解析
- **Pandas**: データ加工・テーブル描画

## 💡 開発で工夫した点・課題解決
- **ボット対策（403エラー）の回避**: `User-Agent` ヘッダーを適切に設定し、ブラウザ通信を擬装することでアクセス遮断を回避。
- **DOM構造の動的解析**: デベロッパーツール（検証）を用いて実際のHTML構造（`.event_list.vevent`）を特定し、見出しタグ（`th`）を起点とした隣接要素（`td`）探索ロジックを構築。
- **UXの向上**: 詳細ページの連続読み込み時の待ち時間でユーザーを不安にさせないよう、インタラクティブな進捗バーを実装。
